# Altavia Elevadores — site estatico

Copia estatica (HTML + CSS + JS puro) do site altaviaelevadores.com.br.

## Publicar no GitHub Pages

1. Crie um repositorio no GitHub e envie todos os arquivos desta pasta na raiz do repo.
2. Va em Settings > Pages > Build and deployment > Source: `Deploy from a branch`.
3. Escolha a branch `main` e a pasta `/ (root)` e salve.
4. Em alguns minutos o site fica no ar em `https://SEU-USUARIO.github.io/SEU-REPO/`.

Paginas: `/` (home), `/projetos/`, `/quem-somos/`, `/aluguel-para-eventos/`, `/contato/`.
O arquivo `.nojekyll` e o `404.html` ja estao incluidos. Todos os links sao relativos,
entao funciona tanto na raiz de um dominio quanto em subpasta do GitHub Pages.
